# FISCO 链上交易所 - 前端界面

这是一个基于 React 的前端界面，用于与 FISCO 链上交易所的后端服务进行交互。

## 功能特性

### 1. 用户管理
- 用户注册（支持景区、银行、做市商、监管机构等角色）
- 用户登录
- 用户信息展示

### 2. 资产管理
- 查看资产余额（总余额、锁定金额、可用余额）
- 资产充值
- 资产提现
- 交易记录查询

### 3. 订单管理
- 提交买单/卖单
- 查询订单详情
- 取消订单
- 订单状态跟踪

### 4. 市场深度
- 实时显示买盘和卖盘
- 支持多档位显示（5档/10档/20档）
- 自动刷新（每5秒）

### 5. 区块链状态
- 区块高度查询
- 节点数量显示
- 共识算法状态
- 交易总数统计
- TPS（每秒交易数）
- 合约信息查询
- 自动刷新（每10秒）

## 技术栈

- **React 18** - 前端框架
- **Axios** - HTTP 客户端
- **CSS3** - 样式设计

## 快速开始

### 1. 安装依赖

```bash
cd frontend
npm install
```

### 2. 启动开发服务器

```bash
npm start
```

前端服务将在 http://localhost:3000 启动

### 3. 构建生产版本

```bash
npm run build
```

## 后端服务配置

前端默认连接以下后端服务：

- **用户服务**: http://localhost:5001
- **资产服务**: http://localhost:5002
- **撮合引擎**: http://localhost:8081
- **区块链服务**: http://localhost:8082

确保所有后端服务已启动。

## 使用说明

### 用户注册和登录

1. 打开应用，默认进入"用户管理"页面
2. 选择"注册"标签，填写用户信息
3. 选择角色（景区、银行、做市商、监管机构）
4. 输入钱包地址（以 0x 开头的以太坊地址格式）
5. 点击"注册"按钮
6. 注册成功后自动登录

### 资产充值

1. 登录后进入"资产管理"页面
2. 选择"充值"标签
3. 选择资产类型（代币/NFT）
4. 输入合约地址
5. 输入充值金额
6. 输入交易哈希（区块链交易凭证）
7. 点击"确认充值"

### 提交订单

1. 登录后进入"订单管理"页面
2. 选择"提交订单"标签
3. 选择订单类型（买入/卖出）
4. 输入 NFT 合约地址
5. 输入 Token ID
6. 输入价格和数量
7. 点击"提交订单"

### 查看市场深度

1. 进入"市场深度"页面
2. 选择显示档位（5档/10档/20档）
3. 查看实时买盘和卖盘数据
4. 数据每5秒自动刷新

### 查看区块链状态

1. 进入"区块链状态"页面
2. 查看区块高度、节点数量、TPS等信息
3. 输入合约地址查询合约信息
4. 数据每10秒自动刷新

## 注意事项

1. **用户登录状态**: 用户登录信息保存在 localStorage 中，刷新页面不会丢失
2. **自动刷新**: 市场深度和区块链状态会自动刷新，无需手动操作
3. **错误处理**: 所有 API 调用都有错误处理，失败时会显示错误信息
4. **区块链服务**: 如果区块链服务未启动，会显示模拟数据并提示用户

## 开发建议

### 添加新功能

1. 在 `src/components/` 目录下创建新组件
2. 在 `src/services/` 目录下添加对应的 API 服务
3. 在 `App.jsx` 中引入并使用新组件

### 修改样式

全局样式在 `src/index.css` 中定义，包括：
- 表单样式
- 按钮样式
- 表格样式
- 状态徽章样式
- 响应式布局

### API 配置

如果后端服务端口发生变化，请修改对应服务文件中的 `API_BASE_URL`：
- `userService.js` - 用户服务
- `assetService.js` - 资产服务
- `orderService.js` - 订单服务
- `blockchainService.js` - 区块链服务
